# 模块考点图（M1-M7）

腾讯云 FDE 备考按 7 个模块切分考点，模块间不重叠。出题时先确定题目归属模块，再写题。

## 模块职责

| 模块 | 名称 | 职责 | 出题重心 |
|---|---|---|---|
| M1 | 概念原理 | 核心概念、名词定义、机制区分 | 部署与精调、推理原理、服务化概念 |
| M2 | 模式与边界选型 | 方案模式、适用条件、选型边界 | 什么场景选什么模式、边界条件判断 |
| M3 | 具体配置与功能 | 控制台配置项、参数作用 | 配置字段含义、功能开关效果 |
| M4 | 需求到组件方案 | 从客户需求映射组件方案 | 需求拆解、组件选型组合 |
| M5 | 行业交付情境 | 分行业交付场景 | 行业痛点、方案落地判断 |
| M6 | 评测/上线/运维 | 评测方法、上线流程、运维动作 | 指标含义、上线步骤、运维排障 |
| M7 | 权限/隐私/责任AI | 权限模型、数据隐私、AI 责任 | 权限边界、合规动作、责任归属 |

## 切分原则

- 同一考点只归一个模块，避免重复出题。
- 跨模块题目以主判断动作归类（例如"选型判断"归 M2，"配置操作"归 M3）。
- 每个模块先列子考点配额，再分批写题。
- 来源清单按模块单独维护（Mn-sources），记录覆盖与不足。

## 默认配额建议

- 短练 15 题：M1-M7 各 2-3 题，覆盖 5-7 个模块。
- 完整 60 题：按模块权重分布，M1/M2/M4 权重略高（概念与选型是考查主体）。
