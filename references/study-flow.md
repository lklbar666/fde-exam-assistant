# 学习工作流

从"要练什么"到"复习计划"的完整流程。所有练习在本地进行，不依赖外部 API。

## 1. 组卷

- 短练：25 分钟 15 题，适合碎片时间。
- 完整练习：90 分钟 60 题，按 M1-M7 权重分布。
- 支持按模块、难度、考点筛选出题；交卷前隐藏解析。

## 2. 作答与判分

- 单选/多选作答，键盘 A-E 快速选择。
- 交卷后逐题显示：正确答案、解析、每个错误选项的错因。
- 计分是练习规则，不承诺复刻官方题型、难度或出题算法。

## 3. 错题与收藏

- 错题进错题本：下次练习优先重现。
- 收藏题单独管理，用于考前重点回看。

## 4. 间隔复习

按掌握度安排重现间隔：未掌握 → 近间隔重现；已掌握 → 拉长间隔。每次答对/答错更新该题掌握度。

## 5. 进度与备份

- 学习进度按题目内容哈希统计；修订后的题目按新哈希分开统计。
- 数据导出为 JSON 备份；恢复时先校验备份结构（validateBackup），再合并（mergeBackup）。
- 多窗口同时作答时，先导出再刷新合并，避免覆盖。

## 边界

- 产品规则会变化，题目附来源核实日期，考前结合来源日期核对。
- 模拟练习结果不构成官方成绩。
